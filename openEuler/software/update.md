
# 鲲鹏核心应用可维护可管理

现阶段，通过antiya上游监控的方式可以获取相关软件的版本发布情况，同步到软件中心。同时，通过对openEuler社区软件扫描，得到当前在openEuler使用的版本。
在软件中心提供了两者比对的看板，计划对看板的结果显示再持续优化，以更直观的方式提供给社区开发者。

## 问题
1、 单应用不唯一，存在歧义。
2、 当前看板功能单一，与社区缺乏联动。
3、 outdated状态优化，实际上相较于上游软件发布，很多软件在各社区引入版本具有滞后性，思考该状态有没有参考意义?

## 改进
1、实际情况应该是每条应用一条监控数据，多种适配方式和版本应聚合。
2、看板考虑增加联动路由机制，风格和其他页面尽量保持统一。
3、后续优化
